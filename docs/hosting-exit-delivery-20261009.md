# 托管退出、数据交付与资源回收：第二批验收

## 完成范围

- 停服任务提交前，客户可以撤回并重新申请；并发停服、旧请求重放和历史原因均有保护。
- 运维制作独立 age 加密交付包，节点经校验后分块上传，支持中断续传。客户登录领取十分钟单次下载授权，独立领取解密密钥；交付包有效七天。
- 导出副本移除平台回报令牌和镜像仓库凭据，保留恢复业务数据所需配置；原冷备份不修改。
- 客户确认交接、保留期届满、工单关闭、无活动任务/有效交付包后，运维可以明确发起本地资源回收。节点核验项目和卷归属、停止状态及备份证据，失败可按原任务重试；收到成功证据后才释放磁盘预算。
- 客户与运维界面、不可变审计、数据库保护、密钥轮换、私有持久卷及到期文件清理均已接入。

## 验证证据

CI：92 项单元、110 项隔离数据库集成、31 项界面组件、4 项浏览器关键路径通过，生产与全量依赖审计为零。包含真实 Docker/PostgreSQL 冷卷恢复及加密导出。

118.25.36.15 上的独立临时实例完成真实冷备份、Restic 加密异机上传/下载、age 加密/解密、丢失响应后的续传以及部分回收后的重试。

额外将真实节点连接至本机隔离数据库上的 Stack API（SSH 加密隧道），完整验证退出申请 → 节点停服及备份 → 制作/上传 → 客户领取密钥与单次下载 → 解密核对 → 客户确认 → 节点回收 → API 记录完成。仅此测试数据库推进保留期时钟；生产保留政策不变。临时资源和测试凭据已清理。

## 明确边界

本批不会终止既有 Retail/Edu，也未做真实收款退款。自动上传、下载和回收的贯通证据来自隔离 Stack API 与真实节点；生产只做只读发布验收。

当前单包 1 GiB、活动上传总量 4 GiB，超限拒绝；外部数据库/对象存储需要相应适配器。回收只删除实例容器、数据卷及部署目录，保留冷快照、异机备份、共享资源和域名占用，不等于全介质销毁。

下一主项为受控升级与整机/跨节点恢复。新教育客户公网交付、专用只读镜像凭据、外部通知、正式定价与真实支付验收继续独立跟踪。
