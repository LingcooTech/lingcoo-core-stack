# 托管退出与退款衔接交付记录（2026-10-09）

## 本轮完成

针对已交付的托管实例，补齐客户申请、运维停服、冷快照和异机备份、保留期限、数据交接确认、分项退款准入。入口位于后台托管实例/部署详情，以及客户部署详情的“服务退出与数据交接”。

退出状态与订单状态分开。未收到停服及备份证据前不释放预算；成功后只释放 CPU/内存，继续保留磁盘。失败任务保留原编号重试，五分钟退避期间允许节点处理其他实例任务。客户确认交接后，财务才可审核全退；不自动决定退款金额。退款失败不恢复可部署资格，退款成功仍保留原部署关联。

退出中的续费、重启、配置修改被阻止；旧续费订单迟到付款进入人工处理回执。节点检查项目/容器/数据卷归属，可写或未声明目录挂载、其他实例共用卷均拒绝。容器自动重启策略关闭，完整卷快照包含配置、镜像信息及 SHA256 校验清单。数据库退出状态有转换保护，事件日志只追加。

## 尚未覆盖的边界

目前的数据交接采用受控人工渠道、平台记录凭证、客户登录确认。自动到期下载授权、独立密钥交付、诊断包和可审计资源回收尚未实现；保留期届满不自动删除数据、DNS 或域名绑定。客户误申请后的撤回流程仍需补充，当前停服前由运维审核，不自动停服。

冷快照面向持久状态位于声明本地卷的应用，恢复需要兼容的数据库/应用镜像。外部数据库或对象存储需要额外的数据交接适配；物理卷备份不能代替跨版本数据迁移。本轮不是整机/跨节点迁移切流验收。

现有 Retail/Edu 正式实例未执行退出，也未执行真实支付/退款；支付参数由用户稍后在后台配置。完整流程模拟、真实容器/数据库恢复、真实异机往返、线上只读检查分别记录，不混同为真实客户资金和退出验收。
