# Stack S3 存储与营销素材管理

## 范围与分工

Stack 的平台图片、营销素材改用与 Edu 一致的 AWS SDK v3 / S3 接口，七牛 Kodo 作为 S3 兼容服务接入。应用镜像仓库、托管实例数据、数据库备份继续使用各自的交付和备份体系，不由营销素材页管理。

后台入口为 `/admin/storage`，配置入口为 `/admin/settings?tab=storage`。交互参照 Edu：左侧文件夹、右侧搜索和类型筛选列表，详情抽屉提供预览、编辑名称/说明/文件夹/可见性、替换文件、版本记录和删除。应用图标、封面、截图及站点图片共用该素材选择器；仍允许填写外部图片 URL。

页面沿用 Stack 的组件、主题和权限体系，不引入另一套 UI 框架。管理员、编辑和运维角色可以管理素材，只有具备 `settings.manage` 的角色可以修改存储凭据。

## 配置与迁移

1. 在七牛空间概览确认 **S3 空间名称**、区域和 S3 服务地址。S3 空间名称可能与原生空间名不同，不能直接假定一致。区域也不能照抄 Edu 示例。
2. 在后台填写区域、S3 服务地址和空间名称。AK/SK 加密保存，不回显，留空保留已有值；配置保存保留现有版本控制和审计。
3. 测试连接执行 `HeadBucket`，仅证明空间可访问。还必须上传、读取、替换和删除一个小文件，才能证明完整读写权限。
4. 默认上传目录为 `stack/assets`，对象键按素材 ID / 版本 / 上传 ID 隔离。目录修改只影响新文件。
5. 可选 CDN 地址只用于公开素材。留空时通过 Stack 的文件接口读取；S3 地址需要签名，不能直接当成公开图片地址。

配置优先级为后台加密设置 → S3 环境变量 → 旧七牛配置提示 → 未配置。旧七牛凭据可以保留用于升级，但必须补齐并验证实际 S3 区域、地址和空间后才允许新上传。生产 Compose 的 API / Worker 都通过 `.env` 加载配置。

旧图片 URL 不批量改写，继续使用原地址。新素材管理页管理本次上线后登记的素材，**不会自动导入或清空整个旧七牛空间**。旧原生上传入口返回 410 并提示使用新页面，原生配置/查询兼容能力暂保留；既有交付协议中的 `qiniu_object` 不做破坏性改名。

当前七牛区域须通过官方查询结果确认。本次线上空间查询得到 `cn-north-1` / `https://s3.cn-north-1.qiniucs.com`，其他环境应重新核实。

## 文件与权限

- 单文件上限 25 MiB，允许 JPEG、PNG、GIF、WebP、AVIF、PDF、UTF-8 TXT / CSV。服务端检查实际内容、声明大小、MIME 和扩展名，并计算 SHA-256；不接受 SVG、HTML、可执行文件。
- 素材页上传默认私有；业务图片选择器上传前明确提示将公开图片。公开链接为 `/v1/assets/{assetId}/content`，私有内容必须通过管理员鉴权接口读取。
- 空间自身应保持私有，且不要为私有对象另设匿名 CDN 入口。平台可见性无法撤销存储服务中另行配置的公开访问；不会自动修改旧空间 ACL，避免影响已有图片。
- 公开素材可通过可选 CDN 读取。业务引用保存稳定的素材链接，替换文件更新当前版本，业务字段不需要随对象键变化。
- 应用、内容、文档及非加密站点设置的 URL / 富文本引用通过数据库触发器登记，与删除共用事务锁。被引用素材不能删除或改为私有；并发写入已删除素材地址会失败。
- 删除需要当前修订号，过时编辑返回冲突。文件夹只允许空文件夹删除。

## 写入与清理

上传先登记 15 分钟授权，再发送二进制文件。服务端验证授权所属账号及内容后，以 2 分钟写入租期执行 S3 上传；远程读写不占用业务引用事务锁。相同上传完成后的重试必须使用相同校验和。

替换文件保留稳定链接，旧对象延迟一小时清理。版本记录保留元信息，**不承诺清理后仍可下载或回滚旧内容**。删除首先关闭平台访问，Worker 再按批次清理对象。过期授权、上传失败、上传期间删除的孤立对象同样进入清理；远程删除失败留待下次重试，错误进入 Worker 日志，不阻断 DNS 对账。

已有未清理对象时禁止直接切换区域、空间或服务地址，避免文件失联。可以更新密钥、默认目录或 CDN 地址。跨空间迁移需单独设计迁移流程。

AWS SDK 使用 `WHEN_REQUIRED` 校验策略兼容七牛的 S3 实现，上传显式附带 Content-MD5，平台另存 SHA-256。服务端共享有界连接池，避免按请求创建客户端时积累空闲连接。Stack 服务端为 CommonJS，`file-type` 为 ESM，因此使用原生动态导入加载内容检测库。

## 验证方式

- `npm run check`：契约构建、格式、数据库结构、模块边界、Lint、类型、单元测试、管理端构建及静态资源检查。
- `npm run test:integration`：在显式指定的隔离测试数据库执行迁移和集成测试；新测试覆盖私有文件、替换稳定链接、引用保护、并发修订、文件夹、上传/删除竞争和失败清理。
- `npm run test:admin`：真实 Chromium 组件交互，覆盖文件夹、上传、详情编辑、替换、只读权限和配置失败草稿保留。
- 生产验收仅操作专属测试文件夹和对象，验证七牛 S3 读写及页面桌面/移动端布局，完成后删除测试素材。
