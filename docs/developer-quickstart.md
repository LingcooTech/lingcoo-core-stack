# Stack 开发者中心

Stack 将应用包装为可售卖、可授权、可交付的产品。开发者维护应用与交付物，平台管理销售、授权、交付版本及托管服务。公开与私有源码仓库均可接入，无需另建公开 delivery 仓库。

## 从这里开始

1. 阅读 [接入与交付标准](stack-application-definition-standard.md)，选择免部署或 Compose 交付。
2. 按 [开发模板说明](../templates/stack-app/README.md) 生成样板，将定义、测试和 CI 合并到应用仓库。
3. 完成应用介绍、功能权益、许可证和使用入口；容器应用还需提供镜像、配置、健康检查、初始化、迁移及备份恢复规则。
4. 本地校验定义，测试应用；容器应用必须实际构建、启动镜像并测试完整服务组合。
5. 在后台“应用管理 → 从仓库或文件导入”读取固定源码提交，预览后创建草稿。
6. 配置 CI，将实测镜像推送 ACR 或兼容仓库，以不可变摘要登记交付版本。凭证存入 CI Secret，不进入定义文件。
7. 在 Stack 配置商品、价格与授权，完成交付验收后发布和上架。版本发布、商品上架、客户实例升级是不同操作。

## 两种交付方式

| 方式               | 应用提供                                               | 用户获得                                   |
| ------------------ | ------------------------------------------------------ | ------------------------------------------ |
| 免部署 `none`      | 在线或下载入口、使用说明、功能声明，收费功能的授权验证 | 按商品规则获得使用权益，进入网站或下载安装 |
| 容器交付 `compose` | 预构建镜像、Compose、参数和生命周期声明、测试证据      | 自有服务器部署或平台托管后的访问地址       |

免部署应用的功能声明不会自动实现鉴权。扩展商店分发和 Stack 销售可以使用同一个应用标识，但应用必须实际接入授权接口，并分别测试购买、查询、到期等流程。不要把服务端密钥放入扩展或网页。

## 技术边界

应用业务代码不限语言和框架。容器交付必须符合平台支持的 Docker/Compose 子集，提供兼容目标服务器架构的镜像，并满足资源、健康、持久化和恢复要求。不能仅凭一个镜像地址交付任意应用。

生成工具及 CI 登记工具的 Node 版本要求只约束这些工具，不要求应用使用 Node。独立实例也不等于独享物理服务器。

## 当前支持状态

| 能力                                            | 状态                                     |
| ----------------------------------------------- | ---------------------------------------- |
| 仓库/文件导入、定义校验、固定提交、交付版本草稿 | 已实现                                   |
| 开发模板、便携校验器、CI 登记、镜像摘要检查     | 已实现；具体应用仍需实际运行验证         |
| 新标准 Compose 部署计划                         | 已实现，只读预览                         |
| 新标准 Compose 通用安装及备份恢复执行           | 尚未完成，容器版本发布门禁保持关闭       |
| 历史适配器部署                                  | 与新标准并存，不代表新标准已完成运行验收 |
| Skill / MCP                                     | 规划中；当前可直接读取本站原始 Markdown  |

详细进度见 [实施任务](../specs/application-lifecycle/tasks.md)。不要将模板、导入成功、结构校验或镜像摘要检查当成生产交付验收。

## AI 开发时如何使用

把本站“接入与交付标准”和“开发模板”的原始 Markdown 地址交给 AI，并要求它：先检查当前能力边界，依据同一版本标准生成定义和测试，运行平台同源校验器，报告未完成的验收。不要要求 AI 猜测字段、把规划能力当作已实现能力，或自动填写真实密钥。

本站文档由 Stack 仓库在构建时生成。机器索引 `/developer-docs/index.json` 提供文档路径、内容摘要和下载地址；标准随平台发布更新。应用中的固定校验工具仍需审查升级，最终以平台接收校验结果为准。
