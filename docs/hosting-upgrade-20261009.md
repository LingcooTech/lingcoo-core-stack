# 受控镜像升级与失败回退验收

## 本批完成

代码提交 `977ae64`，为平台托管实例增加受控镜像升级：节点登记审核版本，平台展示合格目标，管理员确认维护后排队，节点完成冷备份/异机副本、镜像替换和健康验证，再由平台记录结果。

升级计划使用固定源/目标 digest 和含义不可更改的发行编号。平台与节点双重校验应用和白名单；任务不携带脚本或任意命令。升级期间保留资源预算，阻止其他运维、退出和配置修改。未知失败保持维护状态，同一任务可恢复。

失败回退只恢复原配置和镜像，不覆盖数据卷。执行中断后保守回退，不重复执行未知的新版本行为；完成回执丢失可重放同一证据。维护超时和节点失联进入监测。

后台实例卡片新增“受控升级”，显示当前镜像、审核依据、确认输入和历史。客户侧显示维护状态。运维记录同时正确区分升级、加密交付和资源回收。
