# Retail 正式交付前的待办

更新日期：2026-10-08。部署工程已完成本轮生产试点；以下只列仍需商业决策或生产运营准备的事项。

## 已完成

- Stack 生产控制端、托管节点自动执行服务和 DNSPod 专用授权已启用。
- `downloads.lingcoo.com` 已发布版本化安装脚本、无源码部署包、Manifest、Release 和 SHA256。
- Retail 已导入生产 Stack，独立实例通过真实镜像拉取、初始化、自动域名解析、HTTPS、登录验证。
- 默认域名和自定义域名均可访问；客户自己的域名只需配置平台给出的 CNAME/A 与 TXT，无需交出 DNS 密钥。
- 节点每日备份已启用，本轮完成隔离数据库及附件恢复验证。
- 模拟购买、重复支付回调与单次权益发放已验证；生产试点使用有审计的管理员授权，没有伪造已支付订单。
