## 工程侧后续工作

这些不是转交给你的开发任务：发布下载文件、配置商品、国内服务器验收、真实支付验收、托管执行器和云模板、托管资源/域名/备份任务管理，以及前后端分离部署模板，仍由工程侧实施。

Retail 当前 Web 使用 SSR，Worker 持续运行，附件使用本地持久卷。因此本次通过的模板是 Linux Docker Compose 自部署。国内托管和国际托管分别需要适配与验收；不能直接把 Retail Web 当静态文件上传 Pages/Vercel，也不能把整个实例承诺为自动归零成本。托管上线之前会明确各组件的运行资源、存储方式及最低持续费用。
