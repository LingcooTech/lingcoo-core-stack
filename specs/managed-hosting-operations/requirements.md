# 托管运营与通配符证书

1. 平台默认入口使用免费的 `*.app.lingcoo.com` 证书；当证书接近到期时，自动通过 DNSPod DNS-01 续期并更新网关，失败保留旧证书并产生可见异常。
2. 当管理员打开托管管理时，展示两台节点的资产信息、真实资源、容量预算、容器清单、报告时间、证书和备份状态；暂停分配不停止监控及已有实例运维。
3. 当管理员修改节点预算时，不得低于已预留资源；服务器月成本/到期日未知时保留空值，不编造。
4. 当管理员为平台创建的 Retail 实例请求重启或备份时，节点只执行白名单动作，记录请求人、状态、结果；重复请求/回报不会跨实例执行，既有非平台应用仅纳入只读资源清单。
5. 当节点离线、资源紧张、实例不健康、证书临近到期或备份异常时，管理页面展示异常；异机备份加密保存并实测恢复，日志与公开响应不得包含密钥。
6. 完成单元、集成、UI、实际证书/托管任务/备份恢复验证，提交推送并通过生产流水线部署。

本期不引入收费云资源，不停止或自动接管已有业务，不提供任意 shell 控制台。原地应用升级、跨节点迁移、收费暂停与数据销毁需各自受控交付流程，页面不得展示未实现操作。
