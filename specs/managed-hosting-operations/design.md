# 设计

- 证书：成熟 ACME 客户端 lego，固定版本校验摘要，DNSPod CAM 认证只留在签发机。受限 SSH 命令向网关传证书，接收器验证域名、有效期、公私钥匹配和信任链；版本目录与原子指针、重载失败回退。默认域名路由加载通配符证书，自定义域名继续独立 ACME。证书自动续期与实例运行独立。
- 资源：保留 deployment 模块边界，hosting_nodes 增加结构化资产元数据；扩展节点报告总量/可用量、容器清单、CPU/内存采样、证书和备份状态。暂停分配与健康状态独立。
- 运维：持久化 hosting_operations，管理员授权发起，节点凭自己的 token 领取，单实例串行、租约和唯一任务 ID。执行器本地日志防重复，过期中断只标失败，不盲目重复副作用。只允许受控重启应用进程和一致性备份。
- 数据保护：沿用已有一致性备份，异机采用 restic 加密仓库；外传/保留/校验状态上报。恢复先隔离。
- 界面：沿用 Stack 已有设计系统（字体、蓝色主色、Card/Input/Button），工业/工具型信息布局，顶部异常与资源汇总，节点和实例分区，操作历史可展开。颜色使用现有主色约 #2563eb、正文 #0f172a、背景 #ffffff、异常 #dc2626、正常 #15803d；字体沿用 --font-sans，避免引入新字体和新的视觉体系。台账可编辑，运维按钮确认后执行，异步状态明确，不显示 shell 或密钥。
