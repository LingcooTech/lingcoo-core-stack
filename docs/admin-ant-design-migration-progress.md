## 基线

基线版本为 `e9b4d39`，业务运行版本为 `261b158`。完整静态清单见 [迁移基线](admin-ui-migration-baseline.json)，使用 `node scripts/admin-ui-inventory.mjs --assets` 可生成当前页面传递依赖及生产资源清单。

初始工程检查通过格式、schema、边界、lint 和类型检查；本地单元测试有两项因沙箱禁止监听本机端口而失败。阶段一验收改用允许监听的隔离环境，并配置专用测试数据库与 Redis，避免将环境失败计为迁移通过。

## 共享边界

后台与客户门户同属一个前端工程，状态展示和部分托管服务面板存在共享。后台基础控件迁移采用独立目录，公共 UI 入口保留给门户；最终按后台传递依赖清零验收，不能全局替换旧组件后只检查后台页面。

## 阶段一验收

- 固定 `antd@6.6.2`、`@ant-design/icons@6.3.2` 和 `@ant-design/cssinjs@2.1.2`；沿用原 Node、React 与 Vite 工具链。
- 后台 Shell 和登录通过路由懒加载；客户门户继续使用原组件。后台提供独立主题、消息上下文、中文语言和 CSS layer。
- 后台侧栏权限过滤、折叠、移动导航、快捷搜索、账户菜单、明暗与系统主题，以及登录失败保留输入、拒绝普通用户登录均已验证。
- 页面容器、工具栏、三档详情抽屉、异步状态、帮助和表单提交区完成；Storybook 构建通过。
- 浏览器组件测试 45 项通过；集成测试 125 项通过；单元测试 102 项通过，3 项依赖专门运行环境的测试保持既有跳过条件。
- 格式、schema、模块边界、lint、后端与测试类型检查通过；修正登录字段路径类型后，后台类型检查和生产构建通过。生产静态入口检查通过。
- 端到端使用隔离数据库、Redis 与正常登录，覆盖门户订单/权益/部署深链、配置保存数值及版本、权限拦截、后台导航与搜索、小屏菜单和会话注销。
- 本阶段未发布生产；后续业务页面迁移继续在迁移分支验证。

## 阶段二验收

- 8 个列表业务区改用 Ant Design Table、筛选、分页、详情抽屉、确认对话框与 Form；查询参数和操作权限继续使用原接口契约。
- 退款、托管服务期限、退出和数据交接采用独立后台视图；与客户门户共享请求逻辑，门户保留原有交互。
- 查询失败显示错误与重试；用户编辑失败保留字段，放弃修改须确认；退款以分为单位，失败重试保留请求标识。
- 静态依赖盘点确认上述 8 页传递依赖中的旧 UI 文件为零；浏览器组件测试 49 项通过。
- 工程全量检查通过，包括格式、schema、边界、lint、前后端及测试类型、102 项单元测试、生产构建和两个静态入口检查；3 项既有环境条件跳过未计入通过项。
- 隔离环境端到端 5 项通过，覆盖正常登录、门户交付、配置数值及版本、权限、导航和移动端；截图另补等待目标页面内容，避免路由切换中途截图。
- 阶段一分支 CI 与 Docker Verify 已通过；本阶段继续在迁移分支提交，尚未发布生产。
