# 托管退出后的数据交付与本地资源回收

## 客户使用

在部署详情展开“服务退出与数据交接”。停服任务提交前，可以撤回退出申请；平台恢复原实例的续费和运维入口，原有服务周期不改变。若停服已经提交，不能撤回；节点必须先确认停服及备份。

运维点击“制作加密交付包”后，节点校验退出冷快照，以独立 age 密钥加密并分块上传。校验完整文件后显示“可下载”，有效期七天。客户登录后分别操作：

1. 领取下载授权，再下载 `.tar.age` 数据包。授权十分钟内有效，只能使用一次；网络中断后重新领取。
2. 单独下载 `.key.txt` 解密密钥，分开保管。普通管理列表和日志没有密钥，其他客户和非实例所有者不能领取。
3. 核对页面的加密包 SHA256，交由接管运维解密、校验和恢复。平台记录下载开始和密钥领取，客户实际核验后才确认交接。仅开始下载不等于已经验证恢复成功。

使用 [age 官方工具](https://github.com/FiloSottile/age)：

```sh
age --decrypt -i INSTANCE.key.txt -o data.tar INSTANCE.tar.age
mkdir restored
# 先查看归档，再在新建隔离目录中解包。
tar -tf data.tar
tar -xf data.tar -C restored
cd restored
sha256sum --check SHA256SUMS
```

包内包括原实例数据库卷、应用持久文件、配置、镜像信息和校验清单。交付副本会移除 ACR/REGISTRY 镜像仓库凭据和 FD_STACK 平台回报配置，重新生成包内校验清单；原始冷备份不修改。应用数据库密码及解密业务数据所需密钥仍属于客户恢复配置。数据库物理卷恢复需要兼容的数据库/应用镜像；不要覆盖正在运行的实例，不将此包视为跨版本迁移工具。外部数据库、对象存储仍需应用适配器单独支持。

撤销或过期会阻止后续领取密钥和下载；已经下载到客户设备的副本无法远程收回。下载清理失败会重试，文件删除前不再次开放授权。

## 运维边界

回收要求：客户已确认交接、购买约定的保留期届满、无未结束关联工单、无活动运维任务、无有效交付包。运维需输入实例编号并明确确认。平台收到匹配节点证据前不释放磁盘预算。

节点验证项目、容器、卷归属和停止状态。发现额外容器、运行中容器、其他容器引用数据卷等情况时拒绝。执行中断使用同一任务编号继续核对，已删除的资源不误删其他目标。不会使用全局 Docker prune，不删除共享镜像、共享网络或通配符证书。

本批回收只移除本地实例容器、数据卷、部署目录。退出冷快照和异机备份按原政策保留，域名不重新分配。本地运行数据回收不等于全部介质的数据抹除。完整备份销毁、跨节点迁移和外部状态交接属于后续独立能力。

## 工程配置

- API 持久卷：`hosting_handovers:/app/private-handovers`；目录可用 `HOSTING_HANDOVER_DIR` 配置。采用非 root 权限，私有文件不由静态服务公开。
- 当前单包最大 1 GiB，活动上传总额最大 4 GiB，预留至少 512 MiB 文件系统余量；超过额度拒绝，不自动扩容购买。更大的应用可走受控人工交付，后续扩展私有对象存储适配。
- 每次上传最多 1 MiB 原始数据；中断按平台确认的偏移续传。包完成前不可下载，SHA256 不符不会标记成功。
- 制作任务 24 小时内有效；完成后的交付包七天有效。API 每十五分钟清理过期/撤销文件及加密存储的独立密钥，保留元数据和审计记录。
- 节点安装发行版 age/age-keygen 后使用 `upgrade-hosting-exit.py` 更新已审核的托管运行脚本；控制节点仍仅监控。节点成功上传后删除临时交付文件和独立密钥。
- 多 API 副本必须共享该私有持久卷；当前单机运行，未宣称多地域文件交付可用。
- 生产验收不终止或删除既有 Retail/Edu，用独立可丢弃实例验证。
