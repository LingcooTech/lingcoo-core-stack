# 免部署应用接入

这是交付接入模板，不包含您的业务应用实现。将现有应用的源码、构建和测试保留在同一个仓库。

填写 `stack/app.yaml` 的产品信息与真实入口。免费访问、付费解锁、订阅或下载授权应按产品需要实现；声明 features 不会自动给应用增加授权校验。

在 CI 登记前加入实际应用的构建、入口与授权测试。浏览器扩展同时测试从扩展入口购买和从 Stack 购买后获得同一权益，以及未授权、过期和退款后的行为。

从 Stack 生成应用专属 CI 凭证，配置 GitHub Secret `STACK_PUBLISH_TOKEN` 和变量 `STACK_API_URL`。生成的工作流只登记草稿，不会自动上架或发布。
