# 阶段任务

- [ ] 1. 统一应用部署台账：权限、分页筛选、安全投影、详情和售后关联；接口/浏览器测试与上线验证。（需求 1）
- [ ] 2. 软件与托管服务期限分离：独立服务记录、变更审计、续费/到期状态及提醒；商业策略待明确前不自动停机。（需求 2）
- [ ] 3. 完整性检查与主动告警：以部署清单核对运行和备份，通知去重与恢复记录。（需求 3）
- [ ] 4. 上架交付检查：统一发布门槛、专用只读镜像凭据核验、真实支付验收清单。（需求 4）
- [ ] 5. 受控升级与故障恢复：版本/备份/迁移兼容、整机恢复和节点切换演练。（需求 5）
- [ ] 6. 通用应用适配器：以第二应用验证不改核心模块即可接入。（需求 6）
- [ ] 7. 售后和退出流程：诊断上下文、服务目标、数据交接、保留与回收。（需求 7）

## 需用户决定或提供的事项

正式软件/托管价格及周期、服务承诺和保留期；真实付款退款操作；主动通知收件人/渠道；第二个应用样本。工程准备与不依赖这些事项的验证继续进行。
