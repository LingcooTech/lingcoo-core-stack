# 退出交接与回收：第二批

## 验收范围

1. 客户可以在停服任务提交前撤回，恢复原服务；撤回与停服并发只能一个成功。历史原因和每次重新申请保留，旧请求重放不重启流程。
2. 运维可请求节点从已验证冷快照制作 age 加密交付包。每包独立密钥，通过 HTTPS 分块传入平台受限私有存储；校验完整文件后才可下载。客户登录后领取短时、单次下载授权，解密密钥通过独立鉴权操作获取；普通列表、审计、日志不返回密钥。
3. 下载授权过期/消费/撤销不可重用；丢失下载可重新领取。包过期不能继续领取；存储有单包、总量及剩余磁盘限制。
4. 仅完成客户交接且保留期届满的实例允许运维发起本地资源回收。未关闭关联工单、活动运维任务或未过期交付包阻止回收。节点核对停止状态、项目/卷归属、备份证据后执行，未知或失败保留预算，同一任务可恢复重试。
5. 回收释放实例容器/卷及本地部署目录，不删除共享镜像、共享网络、通配符证书或其他客户资源。异机备份保留按原备份政策管理，本批不承诺全介质数据抹除。域名不重新分配给其他客户。

## 设计

延续 deployment 模块独立退出状态；增加交付包、下载授权和回收记录，保留版本与事件审计。数据包位于 API 专用持久卷；数据库只存元数据和使用平台密钥加密的独立 age identity。节点工具使用发行版提供的 age，不自行设计加密格式。传输分块、可续传，完成前不可下载。客户获得加密文件、独立密钥文件及校验信息。

UI 使用现有工业/工具型后台设计：继承项目蓝色主按钮、白/灰背景、正文和字体 token、Lucide 图标；在现有退出折叠区域按顺序展示撤回、交接下载、回收状态。沿用既有设计系统，不另行替换字体或色板。危险操作需清楚列出对象和删除范围。
